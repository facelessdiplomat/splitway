A bug-fix release of Splitway, a free, open-source WireGuard® client for Mac that sends only the apps you choose through the tunnel.

**Requires macOS 26 or later**, on Apple silicon or Intel.

## Fixed

- A tunnel saved by another build of Splitway, for example one built from source, no longer fails with “Couldn’t connect” after you install a release. The network extension now replaces its stored copy of the tunnel configuration instead of updating it, so the installed build can always read it.

## Install

1. Download `Splitway.dmg` below and open it. The app is signed with Developer ID and notarized by Apple.
2. Drag Splitway to Applications, replacing an older version if you have one: the network extension starts only from there.
3. On first launch, allow the extension in System Settings › General › Login Items & Extensions › Network Extensions.
4. Import your WireGuard configuration, allow the VPN configuration when macOS asks, and connect.

To check the download, compare the output of `shasum -a 256 Splitway.dmg` with `Splitway.dmg.sha256`.

## Русский

Исправление для Splitway — бесплатного клиента WireGuard® для Mac с открытым кодом, который пускает через туннель только выбранные приложения.

**Нужна macOS 26 или новее** на Apple silicon или Intel.

### Исправлено

- Туннель, сохранённый другой сборкой Splitway, например собранной из исходников, больше не падает с ошибкой «Couldn’t connect» после установки выпуска. Сетевое расширение теперь заменяет свою копию конфигурации туннеля, а не обновляет её, поэтому установленная сборка всегда может её прочитать.

### Установка

1. Скачайте `Splitway.dmg` ниже и откройте его. Приложение подписано Developer ID и нотаризовано Apple.
2. Перетащите Splitway в «Программы», заменив старую версию, если она есть: сетевое расширение запускается только оттуда.
3. При первом запуске разрешите расширение в «Системные настройки › Основные › Объекты входа и расширения › Сетевые расширения».
4. Импортируйте конфигурацию WireGuard, разрешите конфигурацию VPN, когда macOS спросит, и подключитесь.

Чтобы проверить загрузку, сравните вывод `shasum -a 256 Splitway.dmg` с содержимым `Splitway.dmg.sha256`.
