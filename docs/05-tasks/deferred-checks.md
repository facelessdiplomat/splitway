# Отложенные проверки

По решению D-41 проверки ниже отложены до первой публикации. Код для них готов: они подтверждают работу на устройствах, в сетях и в сценариях, которые сейчас нельзя проверить или проверять долго. Возвращаться к ним лучше сверху вниз: первая строка — самый вероятный повод для отказа на ревью.

| Проверка | Задачи | Что нужно | Зачем |
|---|---|---|---|
| Сеть только с IPv6 (NAT64), смена Wi-Fi и сотовой сети | M5-10 | iPhone в сотовой сети с NAT64 или общий доступ к интернету с NAT64 на Mac владельца | App Review проверяет приложения в сети только с IPv6, отказ по этой причине частый |
| Финальные тесты утечек | M7-05 | iPhone, тестовая ВМ, тестовый туннель | Трафик и DNS не идут мимо туннеля после всех изменений M7 |
| Профилирование памяти на iOS | M7-04 | iPhone | У пакетного туннеля iOS жёсткий предел памяти |
| Матрица стабильности | M7-06 | iPhone, ВМ, смена сетей у владельца | Долгая работа, сон, смена сетей |
| iPad на устройстве | M2-14, M5-07, M5-09, M5-10 | iPad в режиме разработчика, подключённый к Mac | iPad проверен только в симуляторе |
| Час работы выбранных сервисов | M5-09 | iPhone | Утечки памяти на длинной дистанции |
| Приложения сервисов каталога | M5-01 | iPhone с установленными приложениями сервисов | Сами приложения (Telegram, YouTube и другие) работают через туннель |
| VoiceOver | M3-14 | iPhone, iPad, Mac | Ручная проверка доступности |
| QR-сканер камерой | M3-05 | iPhone или iPad | В симуляторе камеры нет |
| Туннель, созданный с нуля, с ключами провайдера | M3-07 | ключи провайдера, вписывает владелец | Подключение к настоящему серверу из редактора |
| «Команды» на iPhone и Siri на iPhone и Mac | M6-03 | iPhone и Mac владельца | Голос в ВМ не проверить |
| Удаление с паролем администратора | M6-02 | пароль администратора, вводит владелец | Снятие системного расширения |
| UI-тесты и интеграционные тесты на macOS | M1-14, M3-14, M3-15 | место для тестов macOS: ВМ с Xcode или отдельный Mac | На Mac владельца UI-тесты забирают курсор (D-32) |
| Отчёт о приватности Xcode | M7-02 | Organizer Xcode, владелец | Манифесты App Store Connect и так проверяет при загрузке |
| Обновление при подключённом туннеле, удаление, повторная установка, чистые macOS 26 и 27 | M7-09, M2-11, M3-10 | сборки из TestFlight, ВМ | Сокращённая M7-09 проверяет только установку и подключение |
| Бета в TestFlight с внешними тестерами | M7-10 | аккаунт организации (D-03) | Отзывы тестеров до выпуска |
| Перетаскивание на лист выбора приложений в песочнице | SP-10 | ручная проверка на Mac | Доступность не умеет перетаскивать файлы |
