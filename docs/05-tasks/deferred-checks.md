# Отложенные проверки

По решению D-41 проверки ниже отложены до первой публикации. Код для них готов: они подтверждают работу в сетях и сценариях, которые сейчас нельзя проверить или проверять долго. Проверки iPhone и iPad ушли вместе с iOS (решение D-45). Возвращаться к ним лучше сверху вниз.

| Проверка | Задачи | Что нужно | Зачем |
|---|---|---|---|
| Сеть только с IPv6 (NAT64) | — | общий доступ к интернету с NAT64 на Mac владельца или ВМ за NAT64 | Подключение по имени сервера через DNS64 и трафик выбранных приложений в сети без IPv4 |
| Финальные тесты утечек | M7-05 | тестовая ВМ, тестовый туннель | Трафик и DNS не идут мимо туннеля после всех изменений M7 и M8 |
| Матрица стабильности | M7-06 | ВМ, смена сетей у владельца | Долгая работа, сон, смена сетей |
| VoiceOver | M3-14 | Mac | Ручная проверка доступности |
| Туннель, созданный с нуля, с ключами провайдера | M3-07 | ключи провайдера, вписывает владелец | Подключение к настоящему серверу из редактора |
| «Команды» и Siri на Mac | M6-03 | Mac владельца | Голос в ВМ не проверить |
| Удаление с паролем администратора | M6-02 | пароль администратора, вводит владелец | Снятие системного расширения |
| UI-тесты на macOS | M1-14, M3-14, M3-15 | место для тестов macOS: ВМ с Xcode или отдельный Mac | На Mac владельца UI-тесты забирают курсор (D-32); интеграционные тесты переносит M8-07 |
| Обновление при подключённом туннеле, удаление, повторная установка, чистые macOS 26 и 27 | M2-11, M3-10, M8-03 | DMG из GitHub Releases, ВМ | M8-03 проверяет установку DMG и подключение |
| Перетаскивание на лист выбора приложений в песочнице | SP-10 | ручная проверка на Mac | Доступность не умеет перетаскивать файлы |
