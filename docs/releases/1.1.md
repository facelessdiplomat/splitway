Splitway can now update itself. Splitway is a free, open-source WireGuard® client for Mac that sends only the apps you choose through the tunnel.

**Requires macOS 26 or later**, on Apple silicon or Intel.

## New

- **Updates inside the app.** Choose Splitway › Check for Updates…, or use the Updates section in Settings. Splitway installs a new version in one step and opens it again.
- **Automatic checks only with your consent.** On the second launch Splitway asks whether to check for updates automatically, once a day. You can change this in Settings at any time.
- **Signed updates.** Splitway installs an update only if it is signed with Splitway's update key and with the developer's Apple certificate, and if the update list is signed too.

When it checks for updates, Splitway asks GitHub, where its releases live, for the list of versions. GitHub sees your IP address and the version of Splitway. Nothing else is sent.

Versions 1.0 and 1.0.1 cannot update themselves: install 1.1 from this page once, and later versions will come in through the app.

## Install

1. Download `Splitway.dmg` below and open it. The app is signed with Developer ID and notarized by Apple.
2. Drag Splitway to Applications, replacing an older version if you have one: the network extension starts only from there.
3. On first launch, allow the extension in System Settings › General › Login Items & Extensions › Network Extensions.
4. Import your WireGuard configuration, allow the VPN configuration when macOS asks, and connect.

To check the download, compare the output of `shasum -a 256 Splitway.dmg` with `Splitway.dmg.sha256`.

## Русский

Splitway теперь обновляется сам. Splitway — бесплатный клиент WireGuard® для Mac с открытым кодом, который пускает через туннель только выбранные приложения.

**Нужна macOS 26 или новее** на Apple silicon или Intel.

### Новое

- **Обновления в приложении.** Выберите Splitway › «Проверить обновления…» или раздел «Обновления» в настройках. Splitway ставит новую версию в одно действие и открывает её снова.
- **Автоматическая проверка только с вашего согласия.** При втором запуске Splitway спросит, проверять ли обновления автоматически, раз в день. Изменить это можно в настройках в любой момент.
- **Подписанные обновления.** Splitway ставит обновление, только если оно подписано ключом обновлений Splitway и сертификатом Apple разработчика, а список версий тоже подписан.

При проверке Splitway спрашивает у GitHub, где лежат его выпуски, список версий. GitHub видит ваш IP-адрес и версию Splitway. Больше ничего не отправляется.

Версии 1.0 и 1.0.1 обновляться сами не умеют: один раз поставьте 1.1 с этой страницы, а следующие версии придут уже через приложение.

### Установка

1. Скачайте `Splitway.dmg` ниже и откройте его. Приложение подписано Developer ID и нотаризовано Apple.
2. Перетащите Splitway в «Программы», заменив старую версию, если она есть: сетевое расширение запускается только оттуда.
3. При первом запуске разрешите расширение в «Системные настройки › Основные › Объекты входа и расширения › Сетевые расширения».
4. Импортируйте конфигурацию WireGuard, разрешите конфигурацию VPN, когда macOS спросит, и подключитесь.

Чтобы проверить загрузку, сравните вывод `shasum -a 256 Splitway.dmg` с содержимым `Splitway.dmg.sha256`.
