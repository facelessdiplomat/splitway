Splitway Support

Splitway is a WireGuard client for Mac that sends only the apps you choose through the tunnel.

Contact

Open an issue on GitHub. Include your macOS version, the Splitway version from Settings and what you did before the problem. Issues are public: never post configurations, keys or crash reports there. If we need a report from Log › Send Report…, we will tell you how to send it privately.

Found a security problem? Report it privately with Report a vulnerability on GitHub instead of a public issue.

Questions

Where do I get a configuration?

From your VPN provider or your own WireGuard server. Splitway does not offer VPN servers: it connects to the ones you add.

How do I add a tunnel?

Import a .conf or .zip file, drop it onto the window, paste a configuration from the clipboard, or create a tunnel from scratch with new keys.

My Mac asks me to allow a network extension

Splitway routes the traffic of the chosen apps through its network extension. Turn on Splitway in System Settings › General › Login Items & Extensions › Network Extensions. On first launch Splitway guides you through it. The extension starts only when Splitway is in the Applications folder.

macOS says the app cannot be opened

Every release is signed with Developer ID and notarized by Apple. If macOS still refuses, download Splitway again from the releases page: copies from other places may be damaged or altered.

Part of an Apple app's traffic bypasses the tunnel

System services make some network requests on behalf of Apple apps, so part of their traffic may go around the tunnel. Splitway marks such apps in the list.

An app or a command-line tool is missing from the list

Splitway lists the apps in the Applications folders. Add any other app or tool with Add Tool… or drag it onto the list.

The server is not responding

The tunnel is connected, but the server has never answered. Check the configuration: the endpoint, the keys, and whether the server is running.

How do I update Splitway?

Download the new version from the releases page and replace the app in the Applications folder. The network extension updates itself the next time Splitway starts.

How do I uninstall Splitway?

In Settings, choose Uninstall Splitway…: it removes the tunnels with their keys, the VPN configurations, the app's data and the network extension. Then drag Splitway from the Applications folder to the Trash.

Privacy

Splitway collects no data. Read the privacy policy.
