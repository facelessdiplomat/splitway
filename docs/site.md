# Сайт

Сайт продукта (решение D-49) — статические страницы из папки `Site/`: без сборки, без счётчиков и без сторонних запросов, шрифты системные. Адрес — `https://facelessdiplomat.github.io/splitway/`, пока у проекта нет своего домена. На бесплатном плане GitHub Pages публикует только публичные репозитории, поэтому сайт заработает после открытия репозитория (M8-06).

## Страницы

| Файл | Что на странице |
|---|---|
| `index.html`, `ru/index.html` | Главная на английском и русском: что делает Splitway, снимки окна, возможности, как это работает, установка, вопросы, кнопка «Скачать для Mac» |
| `en/support.html`, `ru/support.html` | Поддержка: связь через GitHub Issues, закрытые сообщения об уязвимостях, частые вопросы |
| `en/privacy.html`, `ru/privacy.html` | Политика конфиденциальности, абзац в абзац как в [privacy-policy.en.md](privacy-policy.en.md) и [privacy-policy.ru.md](privacy-policy.ru.md). При изменении политики обновите и эти страницы |
| `styles.css` | Одна таблица стилей: светлая и тёмная тема по настройке системы, раскладка для телефона уже 860 точек |
| `images/` | Иконка из `Apps/Shared/AppIcon.icon` (`ictool`, 64, 180 и 256 точек) и снимки окна на двух языках |

Старые страницы `facelessdiplomat.github.io/{en,ru}/{support,privacy}.html` после публикации нового сайта переадресуют на те же страницы под `/splitway/`.

## Скачивание

Кнопки ведут на `https://github.com/facelessdiplomat/splitway/releases/latest/download/Splitway.dmg`. Скрипт выпуска называет образ одинаково в каждом релизе ([03-platform-macos.md](03-platform-macos.md), раздел 9), поэтому ссылка всегда открывает последнюю версию и сайт не надо менять при выпуске.

## Снимки

`images/main-{en,ru}.png` — главное окно с туннелем «Прага», через который идут Safari и Терминал; `images/apps-{en,ru}.png` — лист выбора приложений, обрезанный до самого листа (960 × 1236 точек из снимка окна). Снимки сняты в тестовой ВМ со сборкой в песочнице, ключи и адреса демо-туннелей случайные ([localization.md](localization.md), раздел «Снимки экрана для сайта»). Когда интерфейс заметно изменится, снимки переснимаются так же.

## Проверка и публикация

- `Scripts/check-site.sh` — шаг `Scripts/check.sh`: все относительные ссылки и картинки страниц существуют.
- Публикует workflow «Site» на облачном раннере GitHub после пуша в `master`, если изменилась папка `Site/` (M8-05).
- Посмотреть локально: `python3 -m http.server --directory Site` и открыть `http://localhost:8000`.
