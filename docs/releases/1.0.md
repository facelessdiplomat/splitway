The first public release of Splitway, a free, open-source WireGuard® client for Mac that sends only the apps you choose through the tunnel.

**Requires macOS 26 or later**, on Apple silicon or Intel.

## Install

1. Download `Splitway.dmg` below and open it. The app is signed with Developer ID and notarized by Apple.
2. Drag Splitway to Applications: the network extension starts only from there.
3. On first launch, allow the extension in System Settings › General › Login Items & Extensions › Network Extensions.
4. Import your WireGuard configuration, allow the VPN configuration when macOS asks, and connect.

To check the download, compare the output of `shasum -a 256 Splitway.dmg` with `Splitway.dmg.sha256`.

## What's inside

- **Only selected apps** go through the tunnel: apps and command-line tools, together with their helpers and the processes they start.
- **DNS lookups of selected apps** go through the tunnel too.
- **If the tunnel is down**, selected apps are blocked instead of going direct. You can change this for each tunnel.
- **All traffic** mode with the option to exclude private networks, as in the official client.
- Import from `.conf` files, `.zip` archives and the clipboard, new tunnels with a generated key pair, an editor that checks fields as you type, export.
- Menu bar, launch at login, Shortcuts and Siri, English and Russian.

## Good to know

- Splitway does not update itself yet. To hear about new versions, watch this repository for releases (Watch › Custom › Releases).
- One tunnel is active at a time.
- A background download that macOS finishes after a selected app quits is sent by a system service and goes direct.

## Русский

Первый публичный выпуск Splitway — бесплатного клиента WireGuard® для Mac с открытым кодом, который пускает через туннель только выбранные приложения.

**Нужна macOS 26 или новее** на Apple silicon или Intel.

### Установка

1. Скачайте `Splitway.dmg` ниже и откройте его. Приложение подписано Developer ID и нотаризовано Apple.
2. Перетащите Splitway в «Программы»: сетевое расширение запускается только оттуда.
3. При первом запуске разрешите расширение в «Системные настройки › Основные › Объекты входа и расширения › Сетевые расширения».
4. Импортируйте конфигурацию WireGuard, разрешите конфигурацию VPN, когда macOS спросит, и подключитесь.

Чтобы проверить загрузку, сравните вывод `shasum -a 256 Splitway.dmg` с содержимым `Splitway.dmg.sha256`.

### Что внутри

- **Через туннель идут только выбранные приложения**: программы и утилиты командной строки вместе с их помощниками и процессами, которые они запускают.
- **DNS-запросы выбранных приложений** тоже идут через туннель.
- **Если туннель недоступен**, выбранные приложения блокируются, а не уходят напрямую. Это настраивается для каждого туннеля.
- Режим **«Весь трафик»** с исключением локальных сетей, как в официальном клиенте.
- Импорт из файлов `.conf`, архивов `.zip` и буфера обмена, новые туннели с генерацией пары ключей, редактор с проверкой полей на лету, экспорт.
- Строка меню, запуск при входе, «Команды» и Siri, русский и английский языки.

### Полезно знать

- Splitway пока не обновляется сам. Чтобы узнавать о новых версиях, подпишитесь на выпуски репозитория (Watch › Custom › Releases).
- Одновременно активен один туннель.
- Фоновая загрузка, которую macOS заканчивает после выхода выбранного приложения, идёт от имени системной службы и мимо туннеля.
