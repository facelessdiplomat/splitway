## Качество

### M7-01. Ревью безопасности и модель угроз
`shared` · M · зависит от: M4, M5

**Сделать:** `docs/security.md`: активы (приватные ключи, история подключений), границы доверия (приложение, расширения, XPC, App Group, импортируемые файлы), угрозы и меры. Аудит: атрибуты Keychain; требования подписи XPC; отсутствие ключей в журнале, `providerConfiguration`, `UserDefaults` и crash-логах; предупреждения при экспорте; время жизни ключей в буфере обмена (`expirationDate` и `localOnly` на iOS); защита от zip-бомб и огромных файлов; проверка сообщений провайдеру.
**Тесты сначала:** тест-сканер: после сценария «импорт → подключение → экспорт журнала» в App Group, `UserDefaults` и журнале нет ни одного ключа из фикстуры.
**Готово, когда:** все найденные проблемы закрыты или явно приняты в `docs/security.md`.

## Выпуск macOS

### M7-08. Конвейер выпуска macOS
`macOS` · M · зависит от: M7-02, D-28

**Сделать:** `Scripts/release-macos.sh`: сборка xcframework → archive с Developer ID → `notarytool submit --wait` → `stapler staple` → DMG → подпись EdDSA и обновление appcast для Sparkle → публикация на хостинг, выбранный по решению D-28. Версионирование: SemVer (`CFBundleShortVersionString`) + монотонный номер сборки (`CFBundleVersion`, на нём основана замена расширения). Секреты подписи хранятся только в Keychain машины выпуска.
**Тесты сначала:** не требуются (скрипт выпуска); пробный выпуск в тестовый appcast.
**Готово, когда:** одна команда выпускает нотаризованный DMG, а установленная предыдущая версия видит обновление.

### M7-09. Установка, обновление, удаление на чистых системах

**Тесты сначала:** не требуются (ручная проверка по чек-листу).
