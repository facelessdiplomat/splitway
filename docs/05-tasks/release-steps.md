# Выпуск на GitHub: шаги владельца

Splitway выходит образом DMG с подписью Developer ID и нотаризацией Apple в GitHub Releases (решение D-48), сайт живёт на GitHub Pages (D-49), исходный код открыт под GPL-3.0 (D-46). Аккаунт организации не нужен: Developer ID доступен и личному аккаунту (D-03 закрыто). В каждом шаге сказано, что делаете вы и что делаю я.

## 1. Данные для нотаризации — один раз

Нотаризация идёт от вашей учётной записи Apple Developer, поэтому данные для неё сохраняете вы, в связке ключей этого Mac. Пароли и ключи мне не присылайте. Профиль `splitway-notary` сохранён 2026-11-03.

1. **Соглашения:** на developer.apple.com/account примите обновлённое соглашение, если наверху есть баннер с просьбой его принять. Иначе нотаризация отвечает ошибкой 403.
2. **Пароль приложения:** account.apple.com → «Вход и безопасность» → «Пароли приложений» → «+», название, например, «Splitway notarization». Пароль показывается один раз.
3. **Профиль:** в Терминале этого Mac выполните команду со своим Apple ID и на запрос вставьте пароль приложения:

   ```bash
   xcrun notarytool store-credentials splitway-notary --apple-id <Apple ID> --team-id 8625S77CSU
   ```

   Профиль сохранён, если в конце вывода есть `Credentials saved to Keychain`. Ошибка 401 значит, что вместо пароля приложения вставлен пароль Apple ID или в Apple ID опечатка, 403 — не принято соглашение.
4. **Проверка:** `xcrun notarytool history --keychain-profile splitway-notary` отвечает без `Error`. Скрипт выпуска и раннер CI берут данные из этого профиля.

Вместо пароля приложения подойдёт ключ App Store Connect API с доступом Developer: `xcrun notarytool store-credentials splitway-notary --key <путь к AuthKey.p8> --key-id <Key ID> --issuer <Issuer ID>`. Профиль `notarytool` хранит в защищённой связке ключей вашего сеанса, а не в файле `login.keychain`, поэтому раннер CI видит его, только когда работает в вашем сеансе ([ci.md](../ci.md), раздел «Раннер»).

## 2. Имя в подписи

Сертификат Developer ID называется по владельцу аккаунта Apple Developer: «Developer ID Application: <имя> (8625S77CSU)». Это имя видно каждому, кто посмотрит подпись приложения или образа, и macOS показывает его в некоторых окнах. Проверьте его командой `security find-identity -v -p codesigning | grep "Developer ID Application"`. Показать вместо него название компании можно только с аккаунтом организации.

## 3. Выпуск версии

Описание выпуска на английском и русском лежит в `docs/releases/<версия>.md` и попадает в `master` до тега: без него скрипт выпуска не публикует релиз. Выпуск идёт по тегу:

```bash
git tag -a v1.0 -m "Splitway 1.0" && git push origin v1.0
```

Раннер на этом Mac собирает архив, экспортирует его с подписью Developer ID, нотаризует приложение и образ и создаёт релиз `v1.0` с `Splitway.dmg` и контрольной суммой. Без CI то же делает `Scripts/release.sh 1.0 --publish` из чистой копии `master`. Установку DMG в тестовой ВМ проверяю я. Так 2026-11-03 вышла 1.0 (сборка 452).

## 4. Проверка на вашем Mac

В ВМ 1.0 проверена 2026-11-03 (M8-03): установка из DMG с пометкой карантина, окно Gatekeeper для нотаризованного приложения, замена расширения сборки разработки и подключение в обоих режимах к неотвечающему серверу. Подключение к живому серверу проверяете вы, на своём Mac:

1. Скачайте `Splitway.dmg` со страницы релиза и перетащите Splitway в «Программы» поверх сборки разработки. При первом запуске macOS спросит, открыть ли приложение из интернета: «Открыть».
2. Новое расширение заменит расширение сборки разработки само. Если macOS попросит одобрение, разрешите его в «Системные настройки › Основные › Объекты входа и расширения».
3. Подключите `cz-prg` в режиме «Весь трафик», затем в режиме «Только выбранные приложения». В карточке туннеля должно появиться последнее рукопожатие, а выбранное приложение должно показывать адрес VPN, например на ifconfig.me, тогда как невыбранное — ваш обычный адрес.

Если что-то пойдёт не так, напишите мне, что видно в карточке туннеля и в журнале приложения.

## 5. Открытие репозитория

Когда подготовка закончена (M8-06), я напишу, что всё готово. Публичным репозиторий делаете вы: GitHub → `facelessdiplomat/splitway` → Settings → General → Danger Zone → Change visibility → Public. После этого я включаю GitHub Pages и закрытые сообщения об уязвимостях. До открытия сайт не публикуется, а скачать DMG без входа в GitHub нельзя.

## 6. App Store

App Store не используется. Запись «Splitway Tunnel» в App Store Connect больше не нужна, удалять её не обязательно. Материалы для App Store — тексты, анкеты, заметки и ответ на отказ ревью 2026-11-03 — убраны в M8-06 и остались в истории git.
